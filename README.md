# Crosswind Workers

This repository containers two projects:

- Crosswind Workers - a drop in replacement for the Cloudflare `workers-runtime-sdk` giving you typed, Pythonic APIs.
- Wynd - a replacement for pywrangler, introducing tree-shaking capabilities to reduce worker bundle size.
